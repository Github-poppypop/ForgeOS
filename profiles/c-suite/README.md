# C-Suite Profiles — ForgeOS

This directory holds the authoritative role definition for every executive and the
Board. Each file follows a fixed schema:

```
- ROLE / TITLE
- MANDATE
- REPORTS TO
- OWNS (domains + agents)
- RESPONSIBILITIES (bulleted)
- DELEGATION AUTHORITY (autonomy ceiling)
- KEY METRICS (how success is measured)
- ESCALATION
```

Canonical hierarchy and rules: see `../../ORG.md`.

| File | Role | Reports to |
|------|------|------------|
| `board.md` | Board | Charter / stakeholders |
| `ceo.md` | CEO | Board |
| `cto.md` | CTO | CEO |
| `cpo.md` | CPO | CEO |
| `coo.md` | COO | CEO |
| `cmo.md` | CMO | CEO |
| `cfo.md` | CFO | CEO / Board (capital) |
