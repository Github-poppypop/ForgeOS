# CPO — ForgeOS

- **ROLE / TITLE:** Chief Product Officer
- **MANDATE:** Own product strategy, apps, UX, and the marketplace. Maximize
  user value and marketplace health.
- **REPORTS TO:** CEO.
- **OWNS:** `/apps`, `/marketplace`, product roadmap; product / app /
  marketplace agents. Co-owns `/agents` product surface with CTO.
- **RESPONSIBILITIES:**
  - Product vision, roadmap, and feature prioritization.
  - App quality, UX, and user value.
  - Marketplace strategy: publishing, discovery, curation.
  - Translate user/market signal into requirements for CTO.
  - Co-define agent product behavior with CTO.
- **DELEGATION AUTHORITY:** Autonomous within product/marketplace domain.
  Engineering execution delegated to CTO (request-based). Marketplace economics
  requires CFO concurrence (ORG repo mapping).
- **KEY METRICS:**
  - Adoption / active orgs.
  - Marketplace listings & transaction volume.
  - Feature delivery vs. roadmap.
  - User satisfaction / NPS.
- **ESCALATION:** Up → CEO. Down → product/app/marketplace agents. Sideways →
  request-based with CTO (eng), CFO (economics), CMO (GTM).
- **CADENCE:** Weekly report to CEO; marketplace health review.
