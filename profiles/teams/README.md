# /profiles/teams — ForgeOS Functional Teams

Teams operationalize each C-suite domain. Every team names its C-suite owner and
reporting cadence (ORG §3.1 — single reporting line).

| Team | C-Suite Owner | Function |
|------|---------------|----------|
| platform-team | CTO | Agent runtime, services, infra |
| product-team | CPO | Apps, UX, roadmap |
| marketplace-team | CPO | Listings, discovery, curation |
| delivery-team | COO | Pipelines, QA, release |
| sre-team | COO | Incident response, reliability |
| knowledge-team | COO | Knowledge Universe curation |
| growth-team | CMO | Acquisition, community |
| content-team | CMO | Docs, narrative |
| finance-team | CFO | Budget, analytics, compliance |

Each team subdirectory carries a `TEAM.md` (owner, members, mandate, cadence).
This file is the index; add rows as teams are created.
