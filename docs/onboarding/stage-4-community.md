# Stage 4 — Community

**Time target:** Ongoing

## Goals

- Join the community
- Open a PR or RFC
- Publish a capability to the marketplace
- Help another contributor

## Steps

1. **Star and watch the repo**
   - GitHub: https://github.com/forgeos/forgeos
   - Click ★ Star, then Watch → Custom → Releases, PRs, Issues.

2. **Join Discord**
   - Invite link: posted in the repo README.
   - Introduce yourself in `#introductions`.

3. **Open an RFC (Request for Comments)**
   - Use the template in `docs/adr/` (or open a blank issue tagged `rfc`).
   - Describe the problem, proposed solution, and alternatives considered.

4. **Contribute code**
   - Fork the repo.
   - Create a feature branch: `feat/<your-name>-<feature>`.
   - Open a PR with the prefix `feat(forgeos):`.

5. **Publish to the marketplace**
   - See `docs/tutorials/marketplace-publish.md`.
   - Requires CFO sign-off for external paid listings.

6. **Mentor**
   - Answer issues tagged `good-first-issue`.
   - Review PRs from new contributors.

## Code of Conduct

- Be respectful; align to `GOVERNANCE.md` decision rights.
- No secrets in code or issues.
- Break changes require an ADR + COO/CEO sign-off.
