# ForgeOS Brain Console — durable task ledger

_Last refreshed: 2026-08-19 by forgeos-driver. Source-verified against
`apps/brain-console/src/client/src/App.tsx`, `server.ts`, `src/server/runtime.ts`,
`src/server/features/*`, `src/client/src/features/*`, and live `/api/*` route probes.
The app is TypeScript (React + Express + Vite) served from `dist/` on :7777. Features are
added via a conflict-free discovery layer: server `src/server/features/feat-*.ts` (loaded by
`features/loader.ts` into the runtime router) and client `src/client/src/features/feat-*.tsx`
(discovered by `features/registry.ts` via Vite `import.meta.glob`, mounted by
`features/dispatch.tsx` in App.tsx). New features NEVER edit App.tsx/runtime.ts/server.ts._
