# Constitutional Amendments

This folder records every amendment to the ForgeOS Constitution.

## Protocol
1. An amendment requires an RFC proposing the change.
2. The Board ratifies by supermajority.
3. The Constitution `Version` is incremented (e.g., 1.0.0 → 1.1.0).
4. The change is recorded in the Decision Ledger (linked RFC + Mission).
5. The amended Article is updated and this file gains an entry.
