# FES-005 — Testing Standards

**Version:** 1.0.0 · **Owner:** QA · **Inherit:** all projects

1. Every feature requires automated tests. (Law #6)
2. Pyramid: unit > integration > e2e; e2e covers critical user journeys.
3. Tests are deterministic; no flaky tests in the main gate.
4. Coverage thresholds are defined per project and enforced in CI.
5. Tests run in CI on every PR; failing tests block merge. (Law #2)
6. Test data is isolated; no test mutates shared production data.
