# FES-008 — UI Standards

**Version:** 1.0.0 · **Owner:** Designer / Frontend · **Inherit:** all projects

1. Accessible by default (WCAG 2.1 AA — see FES-012).
2. Responsive; mobile-first where applicable.
3. Consistent design tokens; no hardcoded magic values.
4. Loading, empty, and error states are designed for every view.
5. Dark/light theming supported where the platform requires it.
6. No layout shift; transitions are purposeful.
