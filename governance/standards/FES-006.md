# FES-006 — Documentation Standards

**Version:** 1.0.0 · **Owner:** CMO / Documentation · **Inherit:** all projects

1. Every feature requires documentation. (Law #7)
2. README explains what, why, and how to run.
3. Architecture Decision Records (ADRs) capture significant choices.
4. API docs are generated or maintained alongside code.
5. Governed projects link to the relevant `/governance` standards.
6. Docs are versioned with the code they describe.
