# FES-007 — Security Standards

**Version:** 1.0.0 · **Owner:** Security · **Inherit:** all projects

1. Enforces `laws/SecurityPrinciples.md` and Constitution Article VII.
2. Dependency scanning in CI; known CVEs block merge.
3. Secrets via environment/secret manager; rotation policy defined.
4. AuthN/AuthZ on every protected route.
5. Input sanitized; output encoded (prevent XSS/injection).
6. Audit logging for security-relevant actions.
7. Least-privilege service accounts.
