# FES-001 — Repository Standards

**Version:** 1.0.0 · **Owner:** CTO · **Inherit:** all projects

1. Every project is a git repository with a `main`/`master` branch and protected history.
2. Root contains: README, LICENSE, .gitignore, and (for governed apps) a
   `governance` reference or link to the root `/governance`.
3. Large external repos (e.g. Product codebases) are referenced as **submodules** or
   sibling repos, never copied raw into the ForgeOS repo.
4. Commit messages follow: `<type>(<scope>): <summary>` (feat, fix, docs, refactor,
   test, chore, gov).
5. Every commit links to its Mission or RFC where applicable.
6. No generated artifacts (node_modules, build output, .env) are committed.
