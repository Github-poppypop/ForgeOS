# FES-002 — Coding Standards

**Version:** 1.0.0 · **Owner:** CTO · **Inherit:** all projects

1. Language-specific linters and formatters are mandatory and run in CI.
2. No commented-out code blocks; delete or version-control via history.
3. Functions are small and single-purpose; prefer explicit errors over silent failures.
4. Type safety: strict mode enabled for TypeScript; nullability handled explicitly.
5. Naming: descriptive, consistent with the language's convention.
6. No secrets, API keys, or tokens in source.
7. Async errors are caught; resources (DB, files) are closed in `finally`.
