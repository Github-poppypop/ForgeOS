# FES-012 — Accessibility

**Version:** 1.0.0 · **Owner:** Designer / QA · **Inherit:** all projects

1. WCAG 2.1 AA conformance target.
2. Semantic HTML; ARIA only where native semantics are insufficient.
3. Keyboard operable; visible focus indicators.
4. Color contrast meets AA; not color-alone signaling.
5. Alternative text for meaningful images; captions for media.
6. Accessibility checked in CI (axe/lighthouse) for critical routes.
