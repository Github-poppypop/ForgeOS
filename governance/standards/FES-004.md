# FES-004 — API Standards

**Version:** 1.0.0 · **Owner:** CTO (Backend) · **Inherit:** all projects

1. Every API endpoint is **documented before it ships**. (Law #3)
2. Versioning: prefix routes (`/api/v1`, `/api/v2`); breaking changes get a new version.
3. Consistent error envelope: `{ error, code, details? }` with appropriate HTTP status.
4. Authentication via JWT or equivalent; authorization checked per-route.
5. Input validation on all mutable endpoints (zod/yup/equivalent).
6. Rate limiting and request logging are enabled.
7. CORS is explicit and minimal.
