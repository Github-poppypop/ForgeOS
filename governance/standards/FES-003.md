# FES-003 — Database Standards

**Version:** 1.0.0 · **Owner:** CTO (Database) · **Inherit:** all projects

1. All schema changes are **migrations**, never ad-hoc DDL. (Law #4)
2. Migrations are reversible where feasible.
3. Every table has a primary key; foreign keys are explicit.
4. Sensitive columns are encrypted at rest; secrets never stored in DB in plaintext.
5. Indexes are added for query patterns; N+1 queries are avoided.
6. Connection pooling is configured; timeouts are explicit.
7. The schema is documented and versioned alongside the migration set.
