# /knowledge-universe — ForgeOS Organizational Memory

**Curation owner:** COO · **Contributors:** All roles
**Purpose:** The compound memory of the org — every decision, design, lesson,
and incident, captured so the org gets smarter each cycle.

## Structure
```
knowledge-universe/
  decisions/    # decision records (what was decided, by whom, why)
  incidents/    # incident + post-mortem records
  designs/      # design notes and rationales
  lessons/      # recurring lessons / anti-patterns
  index/        # retrieval index
```

## Rules
- Material decisions are recorded with: goal, owner, authority, date, rationale,
  outcome (ORG §3.5).
- Decisions are immutable; corrections are new records that supersede.
- COO owns ingestion standards and retrieval quality.
- The Knowledge Universe is the source of truth for "why we did X."
